# FCW Builder: live demo

- **Project brief:** https://srg13640.github.io/fcw-builder-demo/
- **Live demo:** https://srg13640.github.io/fcw-builder-demo/app.html

FCW Builder turns an FDW and its sources into a staff-ready Force Capability Workbook. The demo runs entirely in your browser with notional data, and nothing you enter leaves it.

This repository holds only the built site. The source code is in a private repository; ask srg13640 for access.

Independent working prototype. Not an official Army system or website. Not an approval or force-structure decision.
